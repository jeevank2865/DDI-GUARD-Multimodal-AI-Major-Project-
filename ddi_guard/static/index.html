    Project overview

    About DDI-GUARD

    DDI-GUARD — Multimodal Explainable AI for Drug–Drug Interaction Severity Prediction

    D

    Research software for studying DDInter severity labels

    DDI-GUARD combines molecular structure information, ChEMBL 34 drug–target bioactivity, and DailyMed drug-label text to study the Minor, Moderate, and Major labels provided by DDInter. It supports local research inference for drug pairs when a compatible verified model and its required features are available. Results and evaluation tools help explore model behavior and limitations.

    How the implemented workflow works

    1 · Drug pairSelect two supported drugs
    2 · Molecular featuresMolecular graph neural network
    3 · Drug–target featuresRelation-aware graph neural network
    4 · Text featuresTrain-fitted TF-IDF from drug labels
    5 · FusionCross-modal attention and gated fusion
    6 · SeverityResearch classification: Minor, Moderate, Major
    7 · ReviewAvailable evidence and evaluation results

    The full model uses all three modalities when available. Verified fallback checkpoints support molecular + target, molecular-only, or target-only inputs. Text-only inference is not enabled; unsupported pairs return an availability error instead of fabricated features.

    Data sources

    DDInter 2.0Pair interaction records and severity labels
    PubChemCompound records and molecular structures
    ChEMBL 34Drug–target bioactivity records
    DailyMedDrug product label text

    DDInter supplies pair-specific dataset annotations where a record exists. PubChem, ChEMBL, and DailyMed supply compound- or individual-drug context; that information alone does not establish an interaction for a particular pair. Missing source coverage remains missing.

    Implemented features

    Open an existing workspace section:

    The report section previews current application results and supports browser print/save to PDF; it does not create a prediction when inference is unavailable.

    Explainability presents source-linked evidence where available; validated atom/bond attribution and pair-specific causal mechanism explanations are not implemented.

    Responsible use and limitations

    • DDI-GUARD is a research prototype, not a clinically validated product.
    • Local inference works only for supported feature combinations and available verified model artifacts.
    • Source records and drug-specific evidence may be incomplete; predictions may be wrong, especially for previously unseen drugs.
    • Evidence about one drug does not automatically demonstrate an interaction between a pair.
    • Predicted severity is not a confirmed clinical risk or a treatment recommendation.
    DDI-GUARD has not been validated for patient outcomes. Do not use it as a substitute for professional medical advice or clinical decision-making. It is not intended for diagnosis, treatment, prescribing, or medication changes.
